# shumi-share

Зашифрованные итоги года для ссылок «поделиться с подругами» из приложения https://shumi.sirenyov.link
(код — AlexLion89/shumi). Каждый `<id>.json` — итоги, зашифрованные AES-GCM; ключ есть только в самой ссылке
(`shumi.sirenyov.link/y/#<id>.<ключ>`, после «#» — на сервер не уходит), поэтому без ссылки файл не прочитать.
Отозвать ссылку — удалить файл (кнопка «Отозвать» в приложении).

`.nojekyll` — чтобы GitHub Pages отдавал файлы как есть.
